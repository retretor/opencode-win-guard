> Перевод. Основной документ — [README на английском](../../README.md); при расхождении верен он.

Песочница для записи и аварийная остановка агентов [opencode](https://opencode.ai) под **Windows**, чтобы агенты могли работать в папке проекта без присмотра. Без прав администратора, без Docker, WSL и сети.

![Агент пишет вне папки — отказ плагина и Windows; читает файл с ключом — аварийная остановка всех агентов до сообщения пользователя](../media/demo.gif)

| Часть | Что делает |
|---|---|
| **Песочница** (`win-guard-sandbox.js` + запускатель) | Агенты читают всё, а пишут только в папку проекта. Для `edit`/`write` плагин проверяет настоящий путь (с раскрытыми ссылками). Для командной строки запись, удаление и смену прав вне папки запрещает **сама Windows**: команды запускаются с низким уровнем целостности (Low), а метку Low несут только папка проекта и папка кэша. |
| **Секретные файлы** (`secrets.txt`) | Файлы с ключами и паролями получают метку, через которую программы уровня Low не могут читать. Ваши собственные программы ничего не замечают. |
| **Лимиты** | Каждая команда работает в объекте задания (job): жёсткий потолок памяти, чтобы у вас всегда оставалось свободное ОЗУ, минимум свободного места на диске, предельный размер проекта с кэшем. При превышении команда завершается (код 125). |
| **Killswitch** (`win-guard-killswitch.js`) | Проверяет каждый вызов **до выполнения**: текст команды и скрипты проекта, которые она запускает. Явно вредное (чтение ключей, запрос сохранённых паролей у Windows, стирание дисков, отключение защитника, управление opencode снаружи...) сразу останавливает **всех агентов папки**. Рискованное (скачать и запустить скрипт не глядя, отправить файлы наружу, автозапуск) отклоняется. Файл `STOP` в проекте, много отклонённых вызовов подряд или исчезновение большой части файлов проекта тоже останавливают агентов. Остановка переживает перезапуск opencode и снимается, когда вы пишете сообщение. |

Защищает от ошибок агента и от вредных команд, на которые его могли уговорить. Это не стена против программы, специально написанной, чтобы вырваться: прочитайте [модель угроз](../security-model.md) (на английском), прежде чем на неё полагаться.

## Требования

- Windows 10 или 11, NTFS.
- opencode 2.2 или новее (плагинный API V2). Проверено на opencode 2.2.3, Windows 10 22H2.
- Компилятор C# из .NET Framework 4: он входит в Windows, ставить ничего не нужно. Установщик собирает запускатель из исходников в [`launcher/`](../../launcher), готовые программы не скачиваются.
- Для bash нужен Git for Windows: установщик копирует его (около 400 МБ) в папку песочницы, потому что Git Bash стартует на уровне Low только из собственной копии. Без копии (`-NoGit`) у агентов будут PowerShell и cmd.

## Установка

Скачайте исходники [последнего релиза](https://github.com/retretor/opencode-win-guard/releases/latest) (или клонируйте репозиторий) и в PowerShell выполните:

```powershell
cd opencode-win-guard
.\install.ps1 -Folder C:\Users\me\Projects\my-project
```

Затем:

1. **Проверьте `~\.local\share\opencode\sandbox\secrets.txt`** и добавьте файлы с ключами и паролями вашего компьютера. `protect.exe --list` в папке `bin` показывает, что закрыто.
2. Перезапустите opencode и начните сессию в папке проекта. В журнале `~\.local\share\opencode\log\win-guard.log` появится `on for <папка>`.

Обновление: снова `install.ps1` (ваши `secrets.txt` и `win-guard.json` сохраняются). Удаление: `uninstall.ps1` (с `-RemoveData` удаляются ещё копия Git, кэши и настройки).

## Настройки

Файл `~\.config\opencode\win-guard.json`, пример: [win-guard.example.json](../../win-guard.example.json). Подробно ключи описаны в [README](../../README.md#settings-configopencodewin-guardjson):

- `folders`: папки, где агенты под защитой;
- `limits`: свободное ОЗУ, свободный диск, размер папки;
- `agents`: какие агенты под защитой, по умолчанию все;
- `extraTools`: инструменты других плагинов, которые можно разрешить, например `crew_list` и `crew_send` из opencode-crew-mail;
- `alsoWritable`: дополнительные папки для `edit` и `write`;
- `lowLabel`: дополнительные папки с меткой Low, куда смогут писать программы из песочницы, например папка данных программы, собранной в проекте; пути могут начинаться с `%APPDATA%` и других переменных;
- `env`: дополнительные переменные окружения для команд; `${cache}` — папка кэша проекта, `${folder}` — папка проекта;
- `language`: язык записки об остановке: `"en"`, `"zh-CN"`, `"ja"`, `"ko"`, `"es"`, `"pt-BR"`, `"de"`, `"fr"` или `"ru"`.

## Остановить агентов самому

Создайте в папке проекта файл `STOP`: работающие команды завершатся за секунду-две, новые не запустятся, все агенты папки будут прерваны. Чтобы продолжить, удалите файл и напишите агенту.

## Тесты

```powershell
npm test
$env:WIN_GUARD_E2E = "1"; npm run test:e2e
```

Сквозные тесты работают во временных папках с собственным секретным файлом, сами собирают запускатель и возвращают все поставленные метки. Ваши настройки, сессии и песочницу opencode они не трогают, провайдер и аккаунт не нужны.
