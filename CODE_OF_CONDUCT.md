# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and patient, assume good intent, criticise code and ideas rather than people, and accept that maintainers have the final word on what goes in. Harassment, insults and personal attacks are not tolerated in issues, pull requests, discussions or any other space of the project.

To report a problem, contact the maintainers privately: use the contact on the maintainer's GitHub profile, or open a [private security advisory](../../security/advisories/new) and say it is about conduct. Reports are handled confidentially. Maintainers may edit or remove contributions and block participants who break these rules.
