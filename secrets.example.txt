# Files with passwords and keys. Programs in the write sandbox cannot open them (Windows refuses), the read tools of
# the agents refuse them, and a command that names one stops the agents. The list is applied before every command;
# protect.exe --list shows the state. Entries that do not exist on this computer are skipped, so a long list costs nothing.
#
#   ~               your user folder
#   %APPDATA%       your Roaming folder, %LOCALAPPDATA% your Local folder
#   *               matches inside one name
#   a line ending with \   a whole folder (with everything in it)
#   a line starting with !  must be protected before any command runs, if it exists: otherwise the shell is refused
#
# Add what else holds keys or passwords on your computer. Before you remove a line, run protect.exe --undo (in the bin
# folder of the sandbox), then protect.exe --apply again: a file stays closed until its label is taken off.
